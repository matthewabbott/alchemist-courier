## Design Decisions

- **Child ColorRect per cell** instead of `_Draw()` override — gives free per-cell mouse events, easy to swap for TextureRect later
- **Scene tree built in code**, not .tscn editor — grid dimensions are runtime-dependent
- **Two-state interaction model**: IDLE (select from tray) and PLACING (hover ghost, click to place)
- **Namespace:** `AlchemistCourier.Game.Inventory` — first code in `src/Game/`, bridges Core to Godot
- **Bag borders computed via edge detection** — check cardinal neighbors for different/no bag ownership

## Interaction Model

- Click tray item → select, ghost follows mouse over grid
- Left-click on valid position → place reagent
- Right-click / R key → rotate selected reagent
- Right-click on placed reagent (no selection) → remove it back to tray
- Escape → cancel selection

## Known Issues / Next Steps

- No status panels, objective panels, or save/load
- ShapePreview in tray uses raw `_Draw()` — works but could be a shared utility
- Bag tint differentiation is subtle — may need more distinct colors
- No visual feedback animation on placement (just instant color change)
- Grid lines render on top of bag borders in some cases (z-index ordering)
